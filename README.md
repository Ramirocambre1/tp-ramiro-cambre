# Rama GPUS

Sitio web multipágina sobre placas de video NVIDIA y AMD, desarrollado para el Trabajo Práctico Intermedio de Front-End.

## Páginas

- **Inicio:** presentación de la tienda.
- **Productos:** tarjetas de placas de video y enlaces para consultar.
- **Galería:** imágenes de placas de video.
- **Contacto:** formulario para consultas.

## Tecnologías

HTML, CSS, Flexbox, Google Fonts (Inter) y Bootstrap Icons.
